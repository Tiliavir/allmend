# ADR-20261109: Rename to Allmend

Status: Accepted

## Decision
App and repo are renamed from almanac/Almanach to **Allmend** (Alemannic: the
commons shared by a village). Go module `github.com/tiliavir/allmend`, binary
`allmend`, env prefix `ALLMEND_`, database file `allmend.db`. The GitHub repo is
renamed after the rewrite is merged; GitHub redirects old URLs. History is kept.

## Why
The app turns from a personal tracker into a family workbench. The name fits
and is a source of design ideas (shared meadow, logo).
